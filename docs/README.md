## 🔍 Finding Documentation

### Search Tips
1. Use your IDE's search (Cmd+Shift+F) across `.md` files
2. Check the main [README](../README.md) for overview
3. Look in [.github/agents/](../.github/agents/) for specialized agent help
4. Review [CHANGELOG](../CHANGELOG.md) for recent changes

### File Naming Convention
- `UPPERCASE.md` - Main documentation files
- `lowercase.md` - Supplementary guides
- `*_GUIDE.md` - Step-by-step tutorials
- `*_SUMMARY.md` - Quick reference summaries
